# V230 — Professional Resource Cards + Sidebar Accent Lines

## Objetivo
Corregir dos observaciones visuales de V229:
1. Las tarjetas inferiores aún se veían planas frente a las tarjetas superiores.
2. Los colores del sidebar debían ser una sola línea, no un contorno completo.

## Cambios
- CPU / RAM / GPU reciben icono/badge lateral, acento vertical y nueva geometría interna.
- Almacenamiento recibe el mismo lenguaje visual con icono lateral, acento y mejor espaciado.
- Tendencias incorpora tres acentos superiores (CPU/RAM/GPU) y una superficie coherente con el resto del dashboard.
- Sidebar: se eliminan los contornos de color completos y se sustituyen por una sola línea vertical de color por opción.
- La opción activa conserva fondo suave, pero no un marco completo.
- Temas y Actualizaciones usan el mismo patrón de línea única.

## Política
- REAL_OR_NA intacto.
- No se modifica telemetría ni diagnóstico; sólo UI/UX.
