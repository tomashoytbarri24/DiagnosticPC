# VALIDACIÓN V252 — Sidebar single icon controls

Base: V251.

Cambios visuales exclusivos del control del sidebar:

- Sidebar abierto: se muestra únicamente `✕`.
- Sidebar cerrado: se muestra únicamente `☰` en la esquina superior izquierda.
- Ambos controles son iconos planos: sin fondo, sin borde y sin cápsula/cuadro.
- Se conserva el comportamiento de apertura/cierre de V249-V251.
- No se modifica Centro de salud, telemetría, SMART, benchmark ni lógica `REAL_OR_NA`.
