# V218 — Windows Mainline · Steam-like Startup Window Size

## Objetivo
Reducir el tamaño de inicio de CorePulse para que se sienta como una aplicación de escritorio tipo Steam en un monitor 1080p, sin parecer maximizada.

## Cambios
- Tamaño automático y recomendado: **1280×720**.
- Ventana centrada al iniciar.
- Preset Compacto: **1180×680**.
- Preset Amplio: **1560×860**.
- Ocultar/mostrar el sidebar no modifica el tamaño exterior de la ventana.

## Política
- Sólo cambia geometría/UI.
- Se mantiene **REAL_OR_NA** y toda la telemetría existente.
