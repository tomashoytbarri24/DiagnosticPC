# V206 — Windows Mainline · Main Screen Hero Visual Polish

## Objetivo
Pulir la pantalla principal de CorePulse para que se vea más atractiva, manteniendo legibilidad y velocidad de lectura.

## Cambios aplicados
- Se rediseña la **cabecera principal** como hero card.
- Se incorpora **eyebrow**, subtítulo y chips de contexto.
- Las tarjetas de estado superior ganan una presencia visual más fuerte y mejor jerarquía.
- Se añaden encabezados de sección para **Recursos principales**, **Almacenamiento** y **Señales en tiempo real**.
- No se altera la autoridad de los datos: sólo cambia la presentación.

## Política
- Se mantiene **REAL_OR_NA**.
- No se modifica la recolección de telemetría, sólo la UI.
