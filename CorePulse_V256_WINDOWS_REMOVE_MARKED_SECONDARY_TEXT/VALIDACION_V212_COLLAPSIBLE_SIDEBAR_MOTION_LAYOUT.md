# V212 — Windows Mainline · Collapsible Sidebar Motion Layout

## Objetivo
Agregar un botón para ocultar/mostrar el listado lateral de opciones y reacomodar el dashboard de inmediato con una animación breve.

## Cambios aplicados
- Nuevo botón de colapso/expansión del sidebar.
- El sidebar puede pasar de vista completa a vista compacta con iconos.
- El contenido principal se reacomoda inmediatamente al cambiar el ancho lateral.
- Se agrega una estela visual breve tipo *motion blur* durante la animación.
- En modo colapsado se ocultan bloques secundarios y quedan las acciones principales accesibles por icono.

## Política
- Se mantiene **REAL_OR_NA**.
- No cambia la telemetría; sólo la navegación y la presentación.
