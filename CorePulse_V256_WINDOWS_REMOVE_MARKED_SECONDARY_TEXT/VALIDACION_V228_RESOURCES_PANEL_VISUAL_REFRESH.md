# V228 — Resources Panel Visual Refresh

## Objetivo
Pulir la zona inferior del Resumen (hardware, almacenamiento y tendencias) para que use un lenguaje visual más moderno y más cercano al de las tarjetas superiores.

## Cambios aplicados
- Tarjetas CPU / RAM / GPU con esquinas más redondeadas y un poco más de presencia visual.
- Tarjetas de almacenamiento con el mismo lenguaje de superficie premium que el resto del dashboard.
- Tarjeta de tendencias actualizada al mismo estilo visual (misma superficie base, bordes y acento suave).
- Ajustes de altura y espaciado para que la zona inferior se vea menos plana y más coherente con el header superior.

## Política
- Se mantiene REAL_OR_NA.
- No cambia la telemetría; sólo el tratamiento visual del panel Resumen.
