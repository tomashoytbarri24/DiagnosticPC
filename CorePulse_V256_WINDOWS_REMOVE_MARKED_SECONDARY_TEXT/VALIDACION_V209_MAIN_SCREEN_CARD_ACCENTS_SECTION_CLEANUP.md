# V209 — Windows Mainline · Main Screen Card Accents + Section Cleanup

## Objetivo
Aplicar el mismo lenguaje de color suave de las tarjetas superiores al resto del dashboard y eliminar los encabezados de sección que recargaban la lectura.

## Cambios aplicados
- Se eliminan los rótulos/secciones adicionales de: Recursos principales, Almacenamiento y Señales en tiempo real.
- CPU, RAM y GPU ahora reciben un **acento suave lateral** similar al de las tarjetas de estado.
- Las tarjetas de almacenamiento también reciben el mismo acento suave.
- El contenedor de gráficos recibe el mismo lenguaje de color para mayor coherencia visual.

## Política
- Se mantiene **REAL_OR_NA**.
- No cambia la telemetría; sólo el tratamiento visual del dashboard principal.
