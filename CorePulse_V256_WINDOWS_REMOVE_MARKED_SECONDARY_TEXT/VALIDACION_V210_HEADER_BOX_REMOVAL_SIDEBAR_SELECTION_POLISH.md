# V210 — Windows Mainline · Header Box Removal + Sidebar Selection Polish

## Objetivo
Eliminar el recuadro superior pesado del Resumen y pulir la selección del sidebar para que se vea más limpia y premium.

## Cambios aplicados
- Se elimina el **recuadro exterior** del header superior.
- La cabecera queda integrada directamente en el lienzo principal, manteniendo sólo la tarjeta compacta de estado del agente.
- Se reduce el ruido visual superior y mejora la continuidad con las tarjetas de estado.
- La selección del sidebar recibe un **acento lateral fino** y un fondo activo más suave.
- Se ajustan paddings/radios del botón activo para que el seleccionado se vea más pulido.

## Política
- Se mantiene **REAL_OR_NA**.
- No cambia la telemetría; sólo el tratamiento visual del dashboard principal y la navegación lateral.
