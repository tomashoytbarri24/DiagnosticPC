# VALIDACION V249 — Sidebar hamburger toggle

Cambios aplicados sobre V248:

- Se agrega una fila superior dentro del sidebar con botón `☰` y botón `✕`.
- `✕` cierra/oculta el sidebar.
- `☰` dentro del sidebar también permite colapsarlo.
- Cuando el sidebar está oculto, aparece un botón `☰` en la esquina superior izquierda de la ventana para volver a abrirlo.
- Se conserva la paleta original de V248 y la integración del bloque de personalización sin caja interna adicional.
