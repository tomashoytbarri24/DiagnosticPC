# V235 — Resource Status Card Parity

## Objetivo
Hacer que CPU, RAM, GPU y almacenamiento usen la misma composición real de las tarjetas superiores, no sólo detalles decorativos.

## Cambios
- Reconstrucción completa de CPU/RAM/GPU: acento lateral, icono a la izquierda, eyebrow, título, valor, barra y detalle.
- Reconstrucción de almacenamiento con la misma jerarquía visual.
- Eliminación de pills/cápsulas/burbujas anteriores.
- Se mantiene REAL_OR_NA y la misma telemetría real.
